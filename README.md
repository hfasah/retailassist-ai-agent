# RetailAssist AI Agent

An AI agent for retail: answering customer questions, looking up products and orders, and helping with store operations.

## Getting started

```bash
git clone https://github.com/hfasah/retailassist-ai-agent.git
cd retailassist-ai-agent
cp .env.example .env   # then fill in your keys
```

## Project structure

```
.
├── src/          # agent source code
├── tests/        # tests
├── .env.example  # environment variable template
└── README.md
```
